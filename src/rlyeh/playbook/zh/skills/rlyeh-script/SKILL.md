# 写剧本

把导入的跑团记录（`logs/events.jsonl`）改写成 `script/*.md`。格式全文见 [剧本格式](https://github.com/void258/rlyeh-workshop/blob/main/docs/zh/script-format.md)。

## 什么时候用

`replay next` 给出 `script.write`（按记录写或补写剧本）、`script.lint`（修校验错误）。

## 格式速记

```markdown
---
chapter: 1
title: 雾港灯塔
lang: zh-CN
---

【章节：第一章　雾港灯塔】
【BGM：港口】

## 第一幕　熄灭的灯

【背景：雾港码头｜夜｜雾】
旁白：〔带着悬念地讲述〕雾港的灯塔已经三天没有亮过了。
阿洛［警惕］：〔压低声音〕门是从里面锁上的。（举起提灯）
铁锤：〔骂〕{tmd}，让开，看我的！
> 柚子：〔笑着〕矮人的思路总是这么直接。
【骰子：维拉｜察觉｜18｜成功】
```

- 台词：`角色［表情］：〔语气〕正文（动作）{消音词}正文`。表情可以不写；**每句要配音的台词都写〔语气〕**；动作只显示不配音；脏话照原文写在 `{}` 里。
- 旁白：`旁白：……`；场外弹幕：`> 玩家名：……`（玩家名要在 `[players]` 里）。
- 舞台指令单独一行：章节、章节结束、片尾、背景（场景｜变体…）、CG、CG结束、登场（角色｜左/中/右｜受伤/灵体）、退场、特效（震屏/闪白/冲刺/喷火/火焰/寒气/晨光/破门）、骰子（角色｜技能｜点数｜命中/未中/成功/失败/大成功/大失败）、伤害（目标｜数值）、对抗（A 属性 值｜B 属性 值｜结果）、战斗开始、回合、战斗结束、道具、BGM（曲目名，留空是淡出）、音效。
- 背景变体：黄昏、夜、暖光、黎明、晨雾、沉睡、雾、窗外人影、围城。
- **不要手写台词 ID**（行尾的 `^c1-0001`）：写完运行 `replay ids` 补；已有的 ID 永远别改。

## 怎么写

1. 分段读记录（`rlyeh_read_log` 或按行读），一场一场来；先列出这场的大事件，再分章、分幕。
2. 角色台词改成角色的口吻，读起来像剧本，不是聊天记录；GM 的叙述改成旁白；跑团中的场外闲聊（玩笑、吐槽、规则讨论）挑有趣的留成场外弹幕。
3. **润色不改事实**：谁做了什么、掷骰点数和结果、伤害数值照记录，用指令写出来（`【骰子：…】`、`【伤害：…】`、`【对抗：…】`）；不编记录里没有的情节。
4. 补舞台指令：换地点就换背景；重要场面用 CG；战斗用战斗开始 / 回合 / 战斗结束；情绪转折换 BGM（名字要写进 `music.yaml`，见 `rlyeh-music`）。
5. 数字、字母、外号念法不明显的，在 `replay.toml` 的 `[readings]` 写读法（只改配音不改字幕）；字母缩写的脏话在 `[spoken]` 写怎么念。
6. 很长的重复（同一个名字连喊八遍）适当减少，配音模型会停不下来。
7. 写完：`replay lint` → 修错误 → `replay ids` → `replay done script.write`。

## 校验

`replay lint`（或 `rlyeh_lint`）的错误必须修：说话人不在 `cast.yaml`（交给 `rlyeh-cast` 补角色）、场外发言人不在 `[players]`、指令名或参数不对、ID 重复。警告尽量处理：没写语气、表情不存在、数字没写读法。
