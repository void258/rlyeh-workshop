# 美术

每张图一个提示词文件 `art/prompts/<类别>/<名字>.md`：文件头写类别、输出路径、底图和参考图，正文就是提示词，原样交给生图后端。格式见 [项目格式 · 生图提示词](https://github.com/void258/rlyeh-workshop/blob/main/docs/zh/project-format.md#生图提示词-artprompts)。

## 流程

1. `replay art jobs`：按 cast.yaml 和剧本给还没有提示词的图写起步提示词。立绘已经按外貌和表情拼好；背景、CG、道具留着 `<!-- TODO -->`。
2. **你来写**（`art.prompts`）：把每个 TODO 换成具体的描述，见下文。
3. `replay art run`：生图（后台跑）。表情差分会自动合成：只把脸贴回基础立绘。
4. `replay art check`：检查透明背景、拼总览图 `art/_overview/*.png`。能看图就自己看一遍总览图。
5. **审核**（`art.review`，人）：请用户在 `/review/art` 逐张通过或打回。
6. **打回的**（`art.redo`）：读 `review/art-review.json`（或 `rlyeh_reviews kind=art`）里的意见，改对应的提示词，再 `replay art run --marked`。

## 写提示词

- 一条提示词 = 画风（`[art] style`）+ 对象描述 + 构图 + 要避免的东西；`[art] always_append`（默认「不要假细节假纹理」）会自动补在最后。
- **背景**：地点、时间、光线、天气、氛围、画面里有哪些东西；画面里**不要人物**；下方三分之一留给对话框。
- **CG**：谁在做什么、镜头、光线；角色造型要和立绘一致（把外貌写进去）；要和某张定稿图一致时，把它的路径写进文件头的 `refs`。
- **道具**：材质、形状、颜色、特征，单个物件、透明背景。
- 一个团的画风统一；同一个地点的不同时间用背景变体（夜、黄昏……），不必另画一张。
- 血腥描写容易被生图服务拦截：写成不见血的恐怖。
- 不想生成的图在文件头写 `skip: true`；整个人都变了的差分（例如变成亡魂）写 `full_redraw: true`。

## 规矩

- 立绘直接生成透明背景，不要先出纯色背景再抠图（纯色会反光到角色身上）。
- 表情差分只改五官：头部角度、大小、位置不变。
- 用 Codex 生图时：提示词由你写好原样传进去；模型和推理强度只用 `[harness.codex]` 写的；**开始一批真实生图前告诉用户要画多少张**。
- 不覆盖不是工具生成的图：用户自己放进来的图会被收下。
