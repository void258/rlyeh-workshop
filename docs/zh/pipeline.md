# 流水线

> 规格 v0.1 草稿。英文版：[`docs/en/pipeline.md`](../en/pipeline.md)

流水线由若干**阶段**组成。每个阶段写明：读什么、产出什么、AI 做什么、工具做什么、哪里需要人审核，以及从实战里总结的**默认规则**。

## 任务与状态

- 每个阶段拆成**任务**，分三类：
  - `agent`：需要判断的活，交给 AI，例如润色一章剧本、写一批生图提示词；
  - `tool`：工具自己跑完，例如生成配音、渲染；
  - `review`：等人审核，例如选声线、逐句审听。
- `replay next` 给出下一件该做的事（JSON），AI 照着做，做完 `replay done <任务ID>`。
- 阶段状态：`todo` → `running` → `review`（等人）→ `done`；输入变了就变成 `stale`（过期），见 [项目格式 · 状态与增量重建](project-format.md#状态与增量重建-rlyehstatejson)。
- 所有阶段都可以重复执行，只重做过期或没做的部分。

```json
{
  "id": "voice.qa.c1",
  "kind": "agent",
  "stage": "voice",
  "title": "看第一章配音质检结果，决定哪些句子要改读法或重做",
  "inputs": ["build/voice_qa.json"],
  "playbook": "rlyeh-voice",
  "blocked_by": []
}
```

## 1. 导入

- **读**：`logs/raw/` 里的原始导出。
- **产出**：`logs/events.jsonl`，每行一条消息或掷骰：时间、发言人、角色、正文、是否场外、骰子结果。
- **工具**：按格式解析；**合并重叠的多次导出并去重**（实战里 FVTT 导出了好几份，时间有重叠）；按会话切分。
- **人工**：确认所有玩家同意把记录做成公开内容；需要的话把玩家名换成化名（匿名表写在 `replay.toml`）。
- 第一批导入器：FVTT 聊天导出、纯文本。之后：海豹骰等 QQ 骰娘 log、Discord、Roll20。

## 2. 剧本

- **读**：`logs/events.jsonl`、cast.yaml（如果已有）。
- **产出**：`script/*.md`，格式见 [剧本格式](script-format.md)。
- **AI**：
  - 润色成可读的剧本，不能直接照搬记录；分章、分幕。
  - 角色台词改成角色的口吻；旁白交代动作和环境；跑团里的场外闲聊保留成场外弹幕。
  - 每句要配音的台词都标〔语气〕；脏话保留原文，用 `{}` 标出来。
  - 补舞台指令：背景、CG、骰子、伤害、战斗、BGM、音效。
- **工具**：`replay lint` 校验；`replay ids` 补台词 ID。
- **人工**（可选）：在 Studio 里审剧本，意见写进 `review/script-review.json`。

## 3. 角色表

- **AI**：没有现成设定时，按剧情推断外貌、年龄、性别；给每个角色定 3–6 个表情差分（含描述）、名牌颜色、语气→表情规则、声线描述。
- **人工**：确认设定。实战例子：「古瓦是女性」「贝斯特改成十一二岁的小男孩」都是这一步改的。

## 4. 声线

- **AI**：给每个角色写声线设计提示（性别、年龄、音色、说话习惯）。
- **工具**：每个角色生成 3 段候选试听（例如 Qwen3-TTS VoiceDesign）。
- **人工**：在 Studio 的选声线页里挑一段，写入 `review/voice-pick.json`，工具把它记成这个角色的**固定参考**。
- **默认规则**：
  - 每个角色只用一段固定参考。**不要滚动参考**（用前几句生成结果当下一句的参考）：误差会一轮轮累积，越到后面越像机器，还会把参考里的台词接着念出来。
  - 参考音频的文字**不能和剧本台词重复**，否则念到同一句时模型会顺着把参考的后半段接着念下去。
  - 选定的参考如果节奏太慢、太低沉（例如旁白），用同一个音色补念几段节奏普通的话作为附加参考，冲淡原来的念法；**不要换掉用户选好的音色**。
  - 每个角色的声线符合角色性别；不用方言声线；区分角色靠不同的声音，不靠变调。

## 5. 配音

- **工具**：
  - 每句**整句连续生成**：语气写成配音模型的方括号指示，脏话照念（消音在下一步做）。
  - 质检：用语音识别把每句识别回文字，与台词按拼音比相似度，再查时长是否异常。
  - 不合格的句子换种子重做，最多 5 个种子。
- **AI**：看质检报告。识别器听错的可以放过；真念错的改读法（`[readings]`）或改写法再重做。
- **人工**：在 Studio 的审听页逐句听，标「重做」的句子回到工具重做。
- **默认规则**：

| 规则 | 默认值 |
|---|---|
| 质检相似度下限（拼音逐字对比） | 0.75 |
| 识别字数 / 台词字数上限 | 1.4 |
| 时长上限 | 2.5 秒 + 每字 0.42 秒 + 每个省略号 0.5 秒 |
| 重做种子 | 123、7、42、2026、99 |
| 数字、字母缩写 | 必须在 `[readings]` / `[spoken]` 里给出读法 |
| 很长的重复（如同一个名字连喊八遍） | 改读法减少重复次数，否则模型会停不下来（实测念了 65 秒） |

## 6. 消音

- **工具**：用强制对齐（中文：FunASR fa-zh）求出每个字的起止时间，把 `{}` 标出的词换成 1 kHz 的「哔」，输出到 `audio/voice-bleep/`。英文按词对齐；没有对齐模型时可以用 `align = "estimate"` 按字数估算，再多盖一点。
- **默认规则**：
  - 前后各多盖 40 毫秒。
  - 脏字在句首或句尾时，一直盖到音频开头或结尾：对齐给的起点常常落在送气声母之后，会漏出半个字。
  - 消音后再识别一遍，确认听不出原字。

## 7. 美术

- **AI**：按 cast.yaml 和剧本写生图提示词：通用画风 + 对象描述 + 构图；每条都加上 `[art] always_append`（默认「不要假细节假纹理」，能减少噪点）。
- **工具**：调用生图后端；生成总览图；差分合成。
- **人工**：在 Studio 的美术审核页逐张通过或打回，可以写修改意见。
- **默认规则**：
  - 立绘**直接生成透明背景**，不要先出纯色背景再抠图：纯色会反光到角色身上（实测品红背景让兽人皮肤泛紫）。
  - 表情差分：拿基础立绘去改图，提示词写死「头部角度、大小、位置不变，只改五官」；生成后**只把脸部区域贴回基础立绘**，轮廓和透明通道全用基础图。原因是改图结果的透明通道分辨率低，边缘会有锯齿和雾边。
  - 场景和 CG 要保持造型一致：先确定一张定稿图（例如人面巨树的场景图），生成 CG 时把它作为参考图一起给生图后端。
  - 血腥描写容易被生图服务的安全系统拦截，改写成不见血的恐怖。
  - 通过 Codex 生图时：提示词由 AI 写好原样传入；限制模型和推理强度；不让 Codex 自己查资料、找参考图（详见 [AI 接入](agents.md#用-codex-生图)）。

## 8. 音乐

- **AI**：按幕和剧情写曲目表（每段的情绪、配器、速度），并在剧本里放 `【BGM：…】`。
- **工具**：生成、检查、生成循环版本。
- **人工**：在试听页给每段挑一版。
- **默认规则**：
  - 纯音乐容易被音乐模型唱出歌词（实测 YuE2 会哼出英文）。做法：**先只生成乐谱，换种子直到人声声部一个音符都没有，再用这份乐谱渲染成音频**。只是把乐谱里的人声音符改成休止符，不一定有用。
  - 用语音识别检查成品里有没有人声；识别出成串文字的版本不用。
  - 生成长度限制在 2–3 分钟，播放时交叉淡化循环。
  - 片尾曲可以是带词的歌；歌词由 AI 按这次冒险写。
  - 战斗开始自动切战斗曲，结束切回原来的曲子，不需要在剧本里写。

## 9. 音效

- **工具**：自带一套程序合成的音效库（骰子、打击、挥空、喷火、破门、锣、胜利……），自动挂到对应的演出上：
  - 掷骰：滚动声 + 按结果的提示音；未命中加一声挥空。
  - 伤害：按前一次攻击用的武器挑打击声（钝器、利器、重击、灼烧），没有就是被怪物打。
  - 剧情音效（尖叫、低吼、僵尸）由剧本里的 `【音效：…】` 触发，可以用配音模型按角色声线生成。
- **默认规则**：同一个音效设最小间隔（例如僵尸呻吟至少隔 40 秒），重复太多会腻。

## 10. 播放器

- **工具**：`replay build` 把剧本、角色表、素材打包成 `build/player/`（浏览器打开 `index.html` 就能播，`replay preview` 的 `/player` 直接打开它）：图片转 WebP、裁头像；音频用硬链接或复制，不转码；剧本里的指令换成英文规范名和规范值，角色名换成角色 ID。缺的配音、图片、音效、曲子会列出来。
- 播放器功能：标题画面、章节卡、幕名、立绘调度、语气驱动表情、场外弹幕聊天栏、骰子/伤害/对抗/战斗横幅、CG、道具、特效、片尾字幕、记录回看、自动播放、快进、从任意一句开始。界面文字跟着项目语言（中文 / 英文）。
- **默认规则**：
  - 片尾字幕自动生成：主持、玩家和他们的角色、登场人物、`[credits] staff` 里写的栏目，再按实际用到的后端写美术、声线设计、配音、音乐（含授权，例如 YuE2 的 CC BY-NC 4.0）、音效、原始记录；后端要求的署名（例如「Built with Fish Audio」）一定会出现。
  - 伤害的打击声按前一次掷骰的技能名挑（剑、匕首 → 斩击；锤、镐 → 重击；火 → 灼烧；棍、杖、投石 → 钝击），都不中就是重击，可以在 `[player] hit_sounds` 改。
  - 喷火从最近说话、而且在 cast.yaml 写了 `sprite.mouth` 的角色嘴里喷出。
  - 背景变体决定氛围：雾、晨雾有雾气，暖光、黎明、黄昏是暖色浮尘，沉睡有孢子，围城隔几秒撞一次门、房梁落灰（sfx.yaml 里写了 `ambient: siege` 的音效会混进来）。

## 11. 渲染

- **工具**：
  - 用无头浏览器加载播放器的录制模式，注入**虚拟时钟**：计时器、动画帧、`performance.now`、随机数全部由渲染器控制；CSS 动画和过渡暂停，每帧按虚拟时间设到准确位置。
  - 每帧推进 1/帧率 秒再截图，交给 ffmpeg 编码。画面只取决于时间轴，不掉帧，每次渲染结果完全一样。
  - 浏览器里不放声音：播放器把配音、音效、BGM 的时间点记下来，渲染完按这份记录离线混音（说话时压低 BGM、循环接缝交叉淡化、统一响度到 -16 LUFS）。
  - 各章并行渲染再拼接（章与章之间是黑场，没有接缝）。
- **命令**：`replay render` 渲染整部；`--from <台词ID> --seconds 60` 只渲染一段试看；`--chapter 2` 只渲染某章；`--remix` 只重新混音。输出在 `build/video/`：`<名>.mp4` 成片、`<名>_video.mp4` 无声画面、`<名>_events.json` 事件记录、`<名>_audio.wav` 混音。
- 需要 playwright（`uv sync --extra render` 或 `pip install "rlyeh-workshop[render]"`，再 `playwright install chromium`）和 ffmpeg。也可以在 `[render] browser` 写 `msedge` / `chrome`，用系统里装好的浏览器。
- **默认规则**：**不要实时录屏。** 实时录屏会掉帧，也要花和片长一样的时间。只改音频时用 `replay render --remix`，不用重新渲染画面。
- **人工**（可选）：看成片，有问题回到对应阶段。

## 12. 压制

| 预设 | 用途 | 默认参数（实测，40 分钟 1080p60） |
|---|---|---|
| `master` | 母版：`replay render` 直接写出的成片 | H.264 NVENC cq19，约 4.6 GB |
| `share` | 分享 | AV1 NVENC 调参版 cq37（前瞻 32 帧、4 个 B 帧作参考、时域滤波、10 秒关键帧），约 500 MB；或 CPU SVT-AV1 crf38，约 360 MB；音频直接复制 |
| `compat` | 兼容老设备、网页 | H.264 cq26，AAC 160k |

`replay encode share` → `build/video/<名>_share.mp4`。工具自动检测显卡编码器（NVENC / QSV / AMF），先拿一小段画面试一下能不能用，不能用就退回 CPU。预设可以在 `[encode.<名>]` 里改，也可以自己加（见 [项目格式](project-format.md#replaytoml)）。
