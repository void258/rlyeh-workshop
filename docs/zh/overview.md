# 拉莱耶工坊 · 总览

> 规格 v0.1 草稿（M0）。本目录是中文版，英文版在 [`docs/en/`](../en/overview.md)。两版内容一致，有出入时以中文版为准。

## 这是什么

拉莱耶工坊（R'lyeh Workshop）把跑团记录做成**视觉小说式的 replay**：一个可以直接在浏览器里播放的网页，以及逐帧渲染出来的视频。

制作过程由**你自己的 AI** 驱动。第一批支持 Claude Code、Codex、DeepSeek Harness。拉莱耶工坊不内置大模型，它提供四样东西：

- **项目格式和剧本格式**：AI、工具和人都读写同一个项目文件夹。
- **流水线工具**：导入记录、配音、质检、消音、美术后处理、BGM、音效、播放器、渲染、压制。
- **接入层**：命令行 `replay`、MCP 服务、中英双语的流程手册，导出成各家 harness 能读的格式。
- **Studio 图形界面**：项目看板、人工审核页、AI 面板、渲染导出。

这套流程来自一次完整的实战：把《魔王之影》跑团的「羊角旅馆」两次团（约 40 分钟成片，532 句配音）做成 replay。实战里踩过的坑都写成了默认行为，见 [流水线](pipeline.md) 的「默认规则」。

## 设计原则

1. **判断交给 AI，体力活交给工具。** 润色剧本、标语气、写美术和音乐提示词、看质检结果决定要不要重做，这些需要判断，交给 AI；解析、配音、对齐、渲染、混音、压制这些确定性的步骤由工具完成。
2. **项目文件夹是唯一的数据来源。** 全部是纯文本或普通媒体文件，可以 diff、可以放进 git。Studio、AI、手动编辑三方互不冲突。
3. **人工审核是正式关卡。** 选声线、审美术、逐句审听、试听 BGM 必须由人来做。AI 读到审核结果才继续。
4. **后端可替换，不打包模型权重。** 每一类能力（生图、配音、识别、音乐……）都是可替换的后端。软件只调用用户自己装好的模型或服务，并明确提示各自的授权条件。
5. **渲染是确定的。** 视频逐帧渲染，画面只取决于时间轴，不掉帧，同一项目每次渲染结果完全一样。
6. **中文优先，中英双语。** 界面、文档、流程手册都有中英两版；剧本格式两种语言都能写。
7. **默认就做对。** 实战里验证过的做法是默认值，用户不需要先踩一遍坑。

## 不做什么

- 不是跑团平台或 VTT，不负责开团。
- 不提供云服务，所有东西都跑在用户自己的机器上（后端可以是用户自己的云端 API）。
- 不自带、不分发任何模型权重。
- 不替代人的审美：AI 和工具保证流程正确，好不好看由人把关。

## 组成部分

```
┌────────────── Studio（图形界面，中英双语）──────────────┐
│ 项目看板 · 流水线进度 · 审核页 · AI 面板 · 渲染导出        │
└───────────────┬────────────────────────────────────┘
                │ 本地 HTTP（127.0.0.1）
┌───────────────▼────────────── 核心（Python）──────────┐
│ 项目/剧本格式与校验 · 流水线各阶段 · 任务队列 · 可替换后端  │
│ 对外接口：命令行 replay ── MCP 服务 replay mcp ── 流程手册 │
└──┬──────────┬──────────┬──────────┬──────────┬──────┘
 导入记录    美术后端     配音/识别    音乐/音效    渲染/压制
                                               │
                              ┌────────────────▼──────┐
                              │ 播放器（网页，可换主题）    │
                              │ 内置虚拟时钟，供逐帧渲染    │
                              └───────────────────────┘
```

| 部分 | 技术选型 | 说明 |
|---|---|---|
| 核心 | Python 3.11+，用 uv 管理依赖 | 现有工具都是 Python；语音、音频、图像生态都在这边 |
| 本地服务 | Python 标准库 HTTP（由 `replay preview` 扩展而来） | 不多装依赖；Studio、审核页、播放器预览共用一个服务，和命令行、MCP 服务共用同一套实现 |
| Studio | React + TypeScript + Vite；剧本编辑器用 CodeMirror 6 | 先做成网页（`replay studio` 在浏览器里打开），M4 再套 Electron 壳做安装包 |
| 播放器 | TypeScript，无框架 | 同一份数据既能网页播放，也能逐帧渲染 |
| 视频 | ffmpeg | 自动检测 NVENC / AMF / QSV，没有就用 CPU |

## 流水线一览

详见 [流水线](pipeline.md)。

| 阶段 | AI 做什么 | 工具做什么 | 人工关卡 |
|---|---|---|---|
| 导入 | — | 解析记录、合并重复导出、匿名化 | 确认玩家同意 |
| 剧本 | 润色、分幕、标语气/表情/指令 | 校验格式、分配稳定 ID | 可选：审剧本 |
| 角色表 | 按剧情推断外貌、表情差分、配色 | 校验 | 确认设定 |
| 声线 | 写声线设计提示 | 生成候选、固定参考 | **选声线** |
| 配音 | 判断质检结果、改读法 | 整句生成、识别质检、换种子重做 | **逐句审听** |
| 消音 | — | 强制对齐、替换成「哔」 | — |
| 美术 | 写提示词、判断一致性 | 透明背景、差分合成、总览图 | **审美术** |
| 音乐 | 写曲目表和风格提示 | 生成、查人声、循环 | **试听 BGM** |
| 音效 | 在剧本里标剧情音效 | 合成音效库、自动挂到演出上 | — |
| 渲染 | — | 逐帧渲染、按时间轴混音 | 可选：看成片 |
| 压制 | — | 母版 / 分享版 / 兼容版 | — |

## 路线图

| 里程碑 | 内容 | 完成标准 |
|---|---|---|
| **M0 规格** | 本套文档：总览、项目格式、剧本格式、流水线、AI 接入、后端与授权 | 维护者审阅定稿 |
| **M1 核心与命令行** | 把实战工具抽成通用流水线；`replay doctor` 环境自检；一个编出来的示例团 | 示例团不靠 AI、只用命令行从头跑到成片 |
| **M2 接入 AI** | MCP 服务；中英流程手册；导出到 Claude Code / Codex / DeepSeek Harness | 单元测试通过；三家各自的命令行都能读出导出的配置（不调模型） |
| **M3 Studio** | 网页版 Studio（`replay studio`）：新建和打开项目、任务看板（一键运行、实时日志）、内置剧本编辑器（高亮、实时校验）、审核页、AI 面板（导出配置、显示进度、提醒审核）、后端设置和环境检查、渲染压制；中英界面 | 不碰命令行也能做完示例团 |
| **M4 发布 0.1** | Electron 壳和 Windows 安装包；首次运行引导装模型；之后补 macOS / Linux | 新机器从安装到出片 |

「羊角旅馆」作为私有回归测试项目：每次大改动都重新渲染，逐帧和基准成片比对（渲染是确定的，所以可以逐帧比）。它包含真人玩家的聊天记录，**不会**放进公开仓库。
