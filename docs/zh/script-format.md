# 剧本格式

> 规格 v0.1 草稿。英文版：[`docs/en/script-format.md`](../en/script-format.md)

剧本是给人读、给 AI 写、给工具解析的 Markdown。一章一个文件，放在 `script/` 下，按文件名排序。

每种元素都有**中文写法**（全角符号）和**英文写法**（ASCII 符号），两种可以在同一个文件里混用。下文表格左列是中文写法，右列是英文写法。

## 文件头

可选的 YAML 头：

```markdown
---
chapter: 1
title: 羊角旅馆
lang: zh-CN
---
```

没有文件头时，章节号取文件名开头的数字，标题取第一个 `# 一级标题`。

## 元素一览

| 元素 | 中文写法 | 英文写法 | 说明 |
|---|---|---|---|
| 章节标题 | `# 第一章　羊角旅馆` | `# Chapter 1: The Ram's Horn Inn` | 可选，有文件头就不需要 |
| 幕 | `## 第一幕　迷雾边缘` | `## Act 1: Edge of the Mist` | 换幕时清空舞台，显示幕名 |
| 角色台词 | `浓痰：台词` | `Phlegm: line` | 冒号后面是台词 |
| 指定表情 | `浓痰［暴怒］：台词` | `Phlegm[furious]: line` | 方括号紧跟角色名 |
| 语气 | `浓痰：〔怒吼〕台词` | `Phlegm: <roaring> line` | 只给配音用，不显示 |
| 动作 | `（拍桌）` | `*slams the table*` | 显示，不配音 |
| 消音词 | `{tm}` | `{damn}` | 显示原文，配音整句念完后把这段换成「哔」 |
| 旁白 | `旁白：……` | `Narrator: ...` | 旁白的名字在 cast.yaml 里定 |
| 场外弹幕 | `> 小林：……` | `> Kobayashi: ...` | 引用块；用这名玩家所扮演角色的声线配音 |
| 舞台指令 | `【骰子：浓痰｜吐火｜19｜命中】` | `[[roll: phlegm \| breath-fire \| 19 \| hit]]` | 单独占一行 |
| 台词 ID | 行尾 ` ^c1-0001` | 同左 | 稳定 ID，见下文 |

说话人写**显示名**（`浓痰`）或**角色 ID**（`nongtan`）都可以，工具会对照 cast.yaml。场外玩家写玩家名（`小林`、`GM:void`），对照 `replay.toml` 的 `[players]`。

### 台词的完整写法

```
角色［表情］：〔语气〕台词正文（动作）{消音词}台词正文 ^c1-0042
```

- **语气**写在台词正文最前面，会变成配音模型的方括号指示（例如 Drama 3 的 `[怒吼]`）。**每一句要配音的台词都应该写语气**，不写的话配音模型会自己猜，容易念平或念错情绪。
- **表情**可以不写。不写时按 cast.yaml 里该角色的 `face_rules` 用语气关键词挑差分，都不匹配就用默认表情。
- **动作**只显示，配音时去掉。
- **消音词**照常显示（播放器里会标红），配音时整句连续生成，生成后再用强制对齐找到这几个字的位置换成「哔」。字母缩写（`cnm`、`sb`）在 `replay.toml` 的 `[spoken]` 里写好读法，否则配音模型念不出来。

## 舞台指令

格式：`【指令：参数｜参数｜…】`，或英文 `[[command: arg | arg | ...]]`。参数用 `｜` 或 `|` 分隔。

| 中文 | 英文 | 参数 | 效果 |
|---|---|---|---|
| 章节 | `chapter` | 标题 | 全屏章节卡；同时清空上一章的舞台 |
| 章节结束 | `chapter-end` | — | 「完」卡；BGM 淡出，画面压暗 |
| 片尾 | `credits` | — | 片尾字幕（自动生成署名，见 [后端与授权](backends.md)） |
| 背景 | `bg` | 场景｜变体… | 换背景；换地点时清空舞台。变体见下表 |
| CG | `cg` | CG 名 | 全屏 CG，加电影黑边，立绘隐藏 |
| CG结束 | `cg-end` | — | 收起 CG |
| 登场 | `enter` | 角色｜位置｜状态 | 指定角色上场并固定在台上，直到退场。位置：`左/中/右`（`left/center/right`）；状态：`受伤`（`hurt`）、`灵体`（`ghost`） |
| 退场 | `exit` | 角色 | 下场，同时清除状态 |
| 特效 | `fx` | 特效名 | 见下表 |
| 骰子 | `roll` | 角色｜技能｜点数｜结果 | d20 掷骰动画；连续几条会合并成一次多人掷骰 |
| 伤害 | `damage` | 目标｜数值 | 伤害数字；目标有立绘就先上台再挨打 |
| 对抗 | `contest` | A 属性 值｜B 属性 值｜结果 | 左右对决，数值滚动，判胜负 |
| 战斗开始 | `battle-start` | — | 战斗横幅；BGM 自动切战斗曲 |
| 回合 | `round` | 名称 | 回合横幅 |
| 战斗结束 | `battle-end` | — | 结束横幅；BGM 切回战斗前的曲子 |
| 道具 | `item` | 道具名 | 道具展示 |
| BGM | `bgm` | 曲目名 | 交叉淡入换曲；`【BGM：】` 留空表示淡出 |
| 音效 | `sfx` | 音效名 | 播放一个剧情音效（尖叫、低吼……） |

**骰子结果**：`命中 / 未中 / 成功 / 失败 / 大成功 / 大失败`，英文 `hit / miss / success / failure / critical / fumble`。点数 20 和 1 会额外显示 NATURAL 20 / NATURAL 1。

**背景变体**（可叠加）：

| 中文 | 英文 | 效果 |
|---|---|---|
| 黄昏 / 夜 / 暖光 / 黎明 / 晨雾 / 沉睡 | `dusk / night / warm / dawn / mist / dormant` | 调色 |
| 雾 | `fog` | 前景雾气粒子 |
| 窗外人影 | `shadows` | 窗外有人影晃动 |
| 围城 | `siege` | 隔几秒一声撞门、房梁落灰 |

**特效**：

| 中文 | 英文 | 效果 |
|---|---|---|
| 震屏 | `shake` | 画面震动 + 低频震动音效 |
| 闪白 | `flash` | 白闪 |
| 冲刺 | `dash` | 速度线 + 推镜 |
| 喷火 | `breath-fire` | 从说话角色的嘴里喷火（位置取 cast.yaml 的 `mouth`） |
| 火焰 | `flames` | 画面下方燃起火焰 |
| 寒气 | `chill` | 冰霜边框，持续到下一次退场或换背景 |
| 晨光 | `dawn-light` | 光束 |
| 破门 | `door-break` | 重震 + 木屑飞溅 |

不认识的指令会在校验时给出警告，播放器跳过。后端和主题可以注册新的指令和特效。

## 舞台调度规则

不需要在剧本里写谁站在哪，播放器按这些规则自动调度：

1. 谁说话谁上场；同时最多三人，满了就请最久没说话的人下场（`登场` 固定的人不会被请下去）。
2. 说话的人点亮、其他人压暗；旁白时所有人半亮。
3. 换幕、换地点时清空舞台；同一地点只换变体（比如加「窗外人影」）不清空。
4. 单人掷骰时掷骰的人上台；伤害目标有立绘时先上台再挨打。
5. 语气里有「吼、大喊、尖叫、狂笑……」这类词时，立绘跳一下、对话框抖一下。

## 台词 ID

每句台词、旁白、场外弹幕都有一个 ID，配音文件、审核记录、增量重建都靠它。

- 默认格式 `c<章>-<4 位序号>`，例如 `c1-0042`。
- ID 写在行尾：` ^c1-0042`（空格 + `^` + ID）。Studio 和播放器不显示它。
- `replay ids` 给还没有 ID 的行补上 ID，**已有的 ID 永远不改**。插入新台词不会让后面的配音全部错位。
- 没写 ID 的剧本也能用（按顺序编号），但这时在中间插一句，后面所有台词的配音都会对不上。校验会对此给出警告。

## 校验规则（replay lint）

**错误**（必须改）：
- 无法解析的行。
- 说话人在 cast.yaml / `[players]` 里找不到。
- 台词 ID 重复。
- 指令名不认识且没有插件注册；指令参数个数不对。
- `登场` 位置、状态取值非法；骰子点数不是数字。

**警告**（建议改）：
- 要配音的台词没写语气。
- 写了表情但 cast.yaml 里没有这个差分。
- 消音词是字母缩写但 `[spoken]` 里没有读法。
- 台词里有数字或字母但 `[readings]` 里没有读法（例如 `116`、`d4`）。
- 没有台词 ID。
- 声线参考的文本和某句台词重复（会诱导配音模型把参考的后半段接着念出来）。

## 完整示例

下面是一个编出来的小场景，用到了大部分元素：

```markdown
---
chapter: 1
title: 雾港灯塔
lang: zh-CN
---

【章节：第一章　雾港灯塔】
【BGM：开场】

## 第一幕　无人的灯塔

【背景：灯塔底层｜夜｜雾】

旁白：〔带着悬念地讲述〕灯塔已经三天没有亮过了。 ^c1-0001
阿洛［警惕］：〔压低声音〕门是从里面锁上的。（举起提灯） ^c1-0002
米拉：〔不耐烦〕那就撞开。 ^c1-0003

> 小林：〔吐槽〕你们俩谁力量高？ ^c1-0004
> GM:void：〔笑着〕过个力量检定吧。 ^c1-0005

【骰子：米拉｜力量检定｜20｜大成功】
【特效：破门】
米拉［得意］：〔得意大笑〕{tm}的，一脚就开了！ ^c1-0006

【登场：守塔人｜中｜灵体】
【特效：寒气】
守塔人：〔虚弱，断断续续〕别……别点灯…… ^c1-0007
【退场：守塔人】
```

同一段的英文写法：

```markdown
[[chapter: Chapter 1: The Fog Harbor Lighthouse]]
[[bgm: title]]

## Act 1: The Empty Lighthouse

[[bg: lighthouse-ground | night | fog]]

Narrator: <suspenseful> The lighthouse had been dark for three days. ^c1-0001
Arlo[wary]: <whispering> It's locked from the inside. *raises the lantern* ^c1-0002
Mira: <impatient> Then we break it down. ^c1-0003

> Kobayashi: <teasing> Which of you has the higher Strength? ^c1-0004
> GM:void: <laughing> Roll a Strength check. ^c1-0005

[[roll: mira | strength | 20 | critical]]
[[fx: door-break]]
Mira[smug]: <laughing proudly> {Damn}, one kick! ^c1-0006

[[enter: keeper | center | ghost]]
[[fx: chill]]
Keeper: <weak, broken> Don't... don't light the lamp... ^c1-0007
[[exit: keeper]]
```
